# 外观与纸张阅读设置

## 范围

保留 Raindrop 暖纸色、系统字体和 ASTRYX 主题架构。新增独立「外观」页，展示浅色、深色、跟随系统的阅读器缩略预览，独立设置磨砂与阴影。选项在预览中即时呈现，保存后应用到整个界面；取消不写入账户或缓存。个人页保留账户和语言，布局密度移到外观页。阅读配色继续提供自动、纸张、护眼、灰色，并展示真实纸张配色样张；阅读颜色与界面主题独立。

## 设计评审

| Before | After | Why |
| --- | --- | --- |
| 主题埋在个人资料下，只有文字选项 | 独立外观入口、主题缩略图、选中标记和实时样张 | 先看效果，再决定；不把账户与视觉设置混在一起 |
| 浮层磨砂和装饰阴影固定开启 | 两个独立开关，默认开启以保留现有体验 | 兼顾清晰度、性能与个人偏好 |
| 阅读配色只有名称 | 使用现有纸张色的样张和说明 | 让阅读配色的影响范围明确，不覆盖整个应用 |
| 效果依赖浏览器支持 | 不透明背景作为基础，支持时才增强磨砂 | 不支持滤镜或减少透明度时仍可清晰阅读 |

## 数据与兼容

- 在账户偏好中新增 `interfaceBlur`、`interfaceShadows` boolean，默认 true；v1 API 保持不变，v2 严格校验，不接受 null、字符串或未知字段。
- 新增可回滚的 SQLite/PostgreSQL/MySQL migration，升级既有行不改变主题和阅读颜色。
- OpenAPI 是 TypeScript DTO 的源；缓存升级至 schema 4，并迁移 schema 1/2/3，包括首屏 bootstrap，保留旧偏好。
- 生产服务器直接提供首屏主题脚本，并禁止缓存；HTML 在 React 加载前使用同一 neutral 主题。浏览器在阻止主模块加载时也必须恢复旧、新缓存中的主题和材质偏好。
- 磨砂只用于 UI 浮层和工具栏，不对文章正文施加滤镜；关闭阴影不移除 focus outline、选中边框或必要分隔线。
- 局部预览用 `data-mode` 对应的 CSS `color-scheme` 切换，沿用同一套颜色 tokens，使生产构建转换后的 `light-dark()` 也能正确解析；不用仅在内联样式切换模式。浏览器回归检查实际背景变化与缩略图边界，而不仅检查模式属性。

## 动效与可访问性

- 低频设置的指针按压采用 Press feedback（transform），预览状态标记采用 Fade（opacity），复用现有 120–180ms/ease-out tokens。
- 不做整页颜色渐变、阅读导航动画或无意义循环；键盘和 reduced-motion 立即反馈。
- 控件具备名称、选中状态、可见焦点、触摸目标；360px、390px、桌面都无横向溢出。

## 验收

保存、重新加载、账户隔离、旧缓存和数据库迁移；浅/深/系统主题；两个效果开关的四种组合；纸张色在深色外壳中仍保持原色；取消及保存失败；键盘、移动端、减少动态效果。通过前后端测试、契约生成检查、production build 和 Playwright 后，更新至 0.6.0，提交 main、发布 annotated tag v0.6.0，并读回 Release 与构建状态。
