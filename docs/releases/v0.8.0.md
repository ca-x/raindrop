## 文章朗读

- 新增独立的语音插件，可用 OpenAI 兼容 TTS 接口朗读文章。Web 与原生桌面端都提供朗读、暂停/继续和停止图标，长文章逐段播放。
- 可配置 API 地址、密钥、模型、音色和语速，并使用尚未保存的配置真实试听。音色由用户手动选择，支持 Edge 云扬、晓晓等示例及自定义语音 ID，不会按文章语言自动切换。
- 停止、切换文章或注销会取消后续请求并释放播放资源；失败不会自动重发可能计费的语音合成请求。

## 配置与安全

- 语音配置按用户隔离，密钥加密保存、不在配置读取中返回；无鉴权的兼容服务可以不填密钥。并发编辑时会检查配置修订号，避免覆盖另一端的修改。
- 新语音接口仅接受 HTTPS 公网服务，校验 DNS 与实际连接地址，拒绝重定向；限制音频大小、超时与并发。API 网关需要允许普通客户端访问，不能要求浏览器人机验证。
- 插件设置支持中英文、浅色与深色主题；README 补充桌面浏览器与手机端的音色选择截图。[配置说明](https://github.com/ca-x/raindrop/blob/v0.8.0/docs/tts.md)。
- 同时更新 Ammonia 正文清洗、Quinn UDP 与 Rustix 的兼容安全补丁，保留现有数据库与接口版本。

## 升级与下载

- 支持 SQLite、PostgreSQL、MySQL，升级会自动新增独立的语音配置表，保留已有订阅、阅读状态和插件配置。升级前请备份数据库与 Provider 密钥环。
- 此版本为 Web/服务端 `v0.8.0`。原生桌面端独立发布为 `raindrop-desktop-v0.2.0` 开发预览；本地资料库朗读无需外部 Raindrop 服务端。编辑远端语音配置不会自动切换本地文章的朗读服务。
- 下载后请使用附件 `SHA256SUMS` 校验。原生桌面 Linux 需要 GTK 4.14+ 和 ALSA，macOS 应用仍未签名、未公证；桌面版仍非完整双向同步或 Web 全功能对等版。

## 既有依赖限制

- SQLx 0.8 仍依赖受 CVE-2026-119375 影响的 SQLite 绑定。风险需要打开攻击者构造的数据库及配套 WAL 文件；当前导入与备份使用 OPML，不接收 SQLite 文件。请保持数据目录与存储卷仅可信用户可写，不要直接打开或恢复来源不明的数据库与 `-wal` 文件。底层数据库大版本升级另行处理。
- SQLx MySQL 还依赖存在 RUSTSEC-2023-0071 告警的 RSA 版本；当前调用使用公钥加密，不使用该告警针对的私钥操作。这些是限定条件下保留的既有依赖风险，不代表依赖审计已无告警。
