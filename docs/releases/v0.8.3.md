## 从列表收藏，留到稍后再读

文章列表里的星标可以直接点。收藏后文章保留原来的已读状态，列表停在原位。桌面浏览器在指针移入或键盘聚焦时显示可用星标，触屏始终显示。已经收藏的星标常亮。在收藏列表用键盘取消收藏，焦点会移到相邻文章。清空最后一条后，可以直接进入全部文章。

## 读到文末，继续下一篇

正文末尾显示当前列表中下一篇文章的标题。文章离开未读或收藏筛选后，续读仍按原顺序向后走。翻到分页边界可以载入更多，整份列表读完可以返回。

Web 正文支持空格向下翻页、Shift + 空格向上翻页。到达文末后，再按一次空格就打开下一篇。按住空格停在当前文章末尾。切换文章后，键盘焦点会跟到新标题。关闭朗读插件后，正文上方也会收起朗读工具栏。

初次使用、未读清空、尚无收藏和订阅搜索无结果都有对应的提示与操作。本次升级沿用现有数据库结构。
