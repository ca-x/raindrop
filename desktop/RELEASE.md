Rust NSH 原生桌面开发预览：本地运行，无需外部服务端或 Docker。

- 本地订阅、原生三栏阅读、搜索、已读及收藏。
- 多远端连接，显式导入订阅和 AI 配置参考。
- 显式推送新增订阅，仅发送 URL；结果未知只核对，不自动重发。
- 本地退订不删除远端；按来源抑制重新导入。
- SQLite WAL + FULL 持久化，批量导入使用共享核心的原子事务。
- 简体中文 / English 即时切换；浅色 / 深色 / 跟随系统，设置在本机持久保存。

**不是完整双向同步，也不等同 Web 功能对等版。** 旧服务端缺少订阅配置修订、
删除墓碑及幂等回执，所以不会自动传播修改或删除。AI 配置不含密钥，尚不支持远端 AI 执行。
远端登录会话只在内存中保存，重启后需要重新登录。完整 AI/MCP/备份设置、
OPML 界面、系统凭据保险库及自动更新尚未实现。

附件是便携 ZIP；macOS 内含未签名、未公证的 `.app`，Windows 不是安装器。
Linux 需要 GTK 4.14+ 等系统运行库，不是 AppImage。请在下载后校验 SHA256SUMS。
详情和开发命令见仓库 `desktop/README.md`。
